# Caro Brand Reference

## Identity

| Field    | Value                                                        |
| -------- | ------------------------------------------------------------ |
| Name     | Caro Clothing                                                |
| Country  | Sri Lanka                                                    |
| Est.     | 2024                                                         |
| Category | Streetwear / Graphic Tees                                    |
| Tagline  | "Wear the Next Generation"                                   |
| Audience | Men & women, 16–30, Gen Z, digitally native, style-conscious |

## Brand Pillars

1. **BOLD** — Statements, not suggestions. Every design has a POV.
2. **RAW** — No filter, no fakery. Honest about what it is.
3. **FREE** — Oversized fits, open expression. Room to move and be.
4. **LOCAL** — Rooted in Sri Lanka. Worn by the next generation.

## Color System

| Name     | Hex     | Use                                                   |
| -------- | ------- | ----------------------------------------------------- |
| Void     | #0A0A0A | Primary background — foundation of everything         |
| Bone     | #F8F5F0 | Primary text, light-mode surfaces — warm, not cold    |
| Charcoal | #1C1C1C | Secondary surfaces, cards, panels                     |
| Ash      | #B4AFA8 | Secondary text, metadata, captions                    |
| Volt     | #C8FF00 | Accent only — CTAs, highlights, urgency, Gen Z energy |

**Color Rules:**

- Volt is an accent, never a base color. Use sparingly.
- Black and Bone are the primary working pair.
- Never use more than 3 colors in a single layout.
- Volt on Void = maximum impact moments only.

## Brand Voice

### Direct

- Short sentences. No fluff. No corporate speak.
- ✓ "Drop this week. Get it."
- ✓ "New. Black. Sold out soon."
- ✗ "Exciting new collection available"

### Confident

- No permission-asking. No qualifiers.
- ✓ "The only tee you need."
- ✓ "Built different. Priced right."
- ✗ "We think you might like this"

### Cultural

- Sri Lankan at the core. Not pretending to be from elsewhere.
- ✓ "From Colombo to everywhere."
- ✓ "Local made. Global worn."
- ✗ "International streetwear brand"

## Logo Rules

- Always solid — no gradients, no effects, no stretching, no rotation
- Clear space: minimum = height of the "C" on all sides
- Digital minimum: 80px wide
- Never on busy backgrounds
- Versions: Primary (on dark), Reversed (on light), Accent (on Volt)

## Photography Direction

**What to shoot:**

- Neutral grey/white studio backgrounds
- Full body and three-quarter poses
- Real models, real expressions — not overly posed
- Both front and back of garments
- Natural, confident, grounded energy
- Multiple model types, age 16–28, diverse looks

**Editing style:**

- Clean, slightly cool-neutral grade
- High contrast, no overexposure
- Keep fabric texture visible
- Consistent shadow treatment
- No heavy filters or oversaturated edits
- Avoid warm, golden, "influencer" tones
